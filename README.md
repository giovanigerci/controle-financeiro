# Controle Financeiro

Sistema de controle de finanças pessoais desenvolvido em Python com MySQL.

## Tecnologias
- Python 3.13
- MySQL
- python-dotenv
- mysql-connector-python

## Como rodar
1. Clone o repositório
2. Crie o ambiente virtual: `python -m venv venv`
3. Ative: `venv\Scripts\activate`
4. Instale as dependências: `pip install -r requirements.txt`
5. Configure o `.env` com suas credenciais
6. Rode: `python main.py`
